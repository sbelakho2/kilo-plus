# Branding (normative)

Product name: Faktor. The native surface carries zero legacy-brand
tokens: crates faktor-*, env FAKTOR_*, headers x-faktor-*, data dir
.faktor, handshake "faktor server listening on http://127.0.0.1:<port>".

Exceptions (isolated under compat/, never rendered to users): upstream
historical identifiers inside frozen compatibility fixtures and
attribution/license notices.

CI enforces the allowlist recursively over compiled/public assets and
source-controlled user-facing material: Kilo+/Kilo Plus/kilo-plus/kilop
are forbidden outside the allowlist. Visual branding assets are
Faktor's own exact assets — no "+"-logo masking remnants.
